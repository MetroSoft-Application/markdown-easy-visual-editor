## Marpプレビュー用サンプル

以下の32ファイルは、既存MermaidサンプルをMarpスライドに入れた対応版です。各ファイルには1種類の図を含み、Peleによるスライド内描画を確認できます。2種類をまとめた短い例は [33-marp-mermaid.md](33-marp-mermaid.md) を参照してください。

Mermaidフェンスの属性に `{scale=65%}` のように指定すると、その図だけ初期サイズの比率を調整できます。指定範囲は10〜200%で、未指定時は従来のサイズです。記法例は [67-marp-mermaid-sizing.md](67-marp-mermaid-sizing.md) を参照してください。
